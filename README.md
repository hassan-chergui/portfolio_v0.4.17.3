# Simple HTML Portfolio Page

A **single-page portfolio project** built with **HTML and CSS**, featuring smooth **background animations, blur effects, and opacity transitions** for a modern look.

---

## Features

- Fully responsive single-page layout  
- Smooth **background animations**  
- **Opacity and blur effects** for visual depth  
- Sections: Home, About, Contact  
- Clean and minimal design using CSS  

---

## Technologies Used

- **HTML5**  
- **CSS3** (Animations, transitions, opacity, blur)
